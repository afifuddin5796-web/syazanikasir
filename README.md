# 🛒 SyazaniKasir - Offline Pro (PWA)

**SyazaniKasir** adalah aplikasi Kasir (*Point of Sale*) berbasis Web & Progressive Web App (PWA) yang dirancang khusus untuk toko kelontong, sembako, dan UMKM. Aplikasi ini bekerja **100% secara offline** di dalam browser tanpa memerlukan server backend atau database eksternal.

---

## 🌟 Fitur Utama

* 📸 **Kasir & Transaksi Real-time:** Input barang via barcode scanner kamera HP/Webcam atau input manual untuk produk kiloan/eceran.
* 📦 **Manajemen Stok & Database Produk:** Kelola stok barang master, harga jual, hingga upload foto kemasan produk UMKM secara lokal.
* 📊 **Laporan Keuangan & Ekspor Excel:** Rekap riwayat transaksi harian, mingguan, hingga bulanan, serta unduh laporan langsung ke format `.xlsx` (Excel).
* 𝄠 **Cetak Struk & Kirim WA:** Cetak struk ke printer thermal Bluetooth/USB, simpan sebagai gambar PNG, atau kirim rincian belanjaan via WhatsApp.
* ⚡ **PWA & Offline-First:** Dapat di-install sebagai aplikasi desktop/Android via PWA Builder dan diakses tanpa koneksi internet.

---

## 🚀 Cara Penggunaan

1. **Akses Web App:** Buka URL GitHub Pages aplikasi ini melalui browser (Chrome, Edge, atau Safari).
2. **Instal Aplikasi (PWA):**
   * Di Android/Chrome: Klik titik tiga di kanan atas > pilih **"Tambahkan ke Layar Utama"** atau **"Instal Aplikasi"**.
   * Di Desktop/PC: Klik ikon instalasi PWA di ujung bilah alamat (*address bar*).
3. **Mulai Transaksi:** Tambahkan daftar produk Anda pada menu produk, lalu lakukan pemindaian barcode atau pencarian nama barang untuk mulai berjualan!

## 🛠️ Teknologi yang Digunakan

* **HTML5 & Vanilla JavaScript** - Performa cepat dan ringan.
* **Tailwind CSS** - Tampilan antarmuka modern dan responsif.
* **Service Worker & Web App Manifest** - Fitur *offline-first* dan instalasi PWA.
* **Html5-QRCode** - Library pemindai barcode via kamera.
* **SheetJS (XLSX)** - Fitur rekap dan ekspor data ke Excel.
